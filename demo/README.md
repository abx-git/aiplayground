# Spring Boot Ollama Demo

This project is a simple Spring Boot application that demonstrates how to integrate with Ollama using the Spring AI library.

## Prerequisites

1.  **Java 17 or higher:** Make sure you have Java 17 or a later version installed.
2.  **Maven:** This project uses Maven for dependency management and building.
3.  **Ollama:**
    *   Ollama must be installed and running. You can download it from [https://ollama.com/](https://ollama.com/).
    *   Ensure the Ollama API server is accessible at `http://localhost:11434` (this is the default and is configured in `src/main/resources/application.properties`).
    *   You need to have a model downloaded. This demo is configured to use `llama2` by default (see `application.properties`). You can download it by running:
        ```bash
        ollama pull llama2
        ```
        If you wish to use a different model, update the `spring.ai.ollama.chat.options.model` property in `application.properties` and ensure that model is pulled via `ollama pull <your-model-name>`.

## Building the Project

1.  Clone the repository or download the source code.
2.  Navigate to the project's root directory (`demo`).
3.  Run the following Maven command to build the project:

    ```bash
    ./mvnw clean install
    ```
    On Windows, you might need to use `mvnw.cmd clean install`.

## Running the Project

Once the project is built successfully, you can run it using the following command:

```bash
java -jar target/demo-0.0.1-SNAPSHOT.jar
```

The application will start, and the Spring Boot services will be available. By default, the application runs on port `8080`.

## API Endpoint

The application exposes a single POST endpoint to generate text using Ollama.

*   **URL:** `http://localhost:8080/api/ollama/generate`
*   **Method:** `POST`
*   **Request Body:** Plain text string (the prompt for Ollama)
*   **Content-Type:** `text/plain`
*   **Response:** Plain text string (the response from Ollama)

### Example Request

You can use `curl` or any API client like Postman to send requests.

**Using `curl`:**

```bash
curl -X POST -H "Content-Type: text/plain" -d "Why is the sky blue?" http://localhost:8080/api/ollama/generate
```

**Expected Response (example):**

The response will be a string generated by the Ollama model based on your prompt. For example:

```
The sky appears blue because of a phenomenon called Rayleigh scattering...
```

## Configuration

The main configuration is in `src/main/resources/application.properties`:

*   `spring.ai.ollama.base-url`: The base URL for the Ollama API server. Defaults to `http://localhost:11434`.
*   `spring.ai.ollama.chat.options.model`: The Ollama model to use. Defaults to `llama2`.

## Project Structure

*   `src/main/java/com/example/demo/DemoApplication.java`: The main Spring Boot application class.
*   `src/main/java/com/example/demo/OllamaService.java`: Service class that interacts with `OllamaChatClient`.
*   `src/main/java/com/example/demo/OllamaController.java`: REST controller that exposes the API endpoint.
*   `src/main/resources/application.properties`: Application configuration.
*   `pom.xml`: Maven project configuration.
*   `src/test/java/com/example/demo/OllamaServiceTest.java`: Unit tests for `OllamaService`.

## Running Tests

To run the unit tests:

```bash
./mvnw test
```
